This demo runs the actual DSP from the Proximate plugin — the balance detector, the gain computer and the first-order shelf in Source/DSP/Compensator.cpp — compiled unmodified to WebAssembly and running in an AudioWorklet. The knob, the meters and the ceiling are the plugin’s; the readouts come from the same code the plugin’s editor reads.

What you’re hearing: a directional microphone picks up more bass the closer the source is. The Distance slider stands in for that — it puts a handheld dynamic’s near-field rise on the source before Proximate hears it, and Proximate only ever hears the audio. Drag the talker in and the low end swells; with Proximate on, the balance is held under the ceiling and the shelf takes the swell off. The before button hears the microphone as it would be without the plugin. Nothing here boosts anything, and the plugin adds no latency.

The synthesised voices are built in your browser — a pulse train through three vowel formants, no recordings, no third-party media. Your microphone and any file you load never leave the page. The “safety clip” output stage is web-only. Parts of this project were built with AI assistance; the DSP core is verified against a native build of the plugin’s own sources. © Stoatworks Labs, MIT.
